# 重复文件清理工具

基于 Everything 快速搜索 + NTFS 符号链接/硬链接技术的重复文件查找与清理工具。

**最新版 v0.1.0**：[📥 DuplicateCleaner.exe (51 MB)](https://github.com/loushijushi/DuplicateCleaner/releases/tag/v0.1.0)

[查看所有版本 →](https://github.com/loushijushi/DuplicateCleaner/releases)

## 功能特性

- 🚀 **极速搜索**: 利用 Everything 索引数据库，秒级搜索指定目录下所有文件
- 🔍 **三重校验**: 文件大小 → 修改时间 → 指纹(xxHash64 + SHA256) 三重比对，确保 100% 识别重复文件
- 🔗 **智能链接**: 自动检测文件系统支持，NTFS 使用符号链接，FAT32/exFAT 自动回退到硬链接
- 🎯 **人工确认**: 直观的分组界面，支持全选/反选/单选，每一步都由用户确认
- 📊 **详细日志**: 实时显示扫描进度和处理结果
- 🗂️ **链接分析工具** (Ctrl+L): 扫描识别硬链接/符号链接/目录联接，支持 CSV/JSON 导出
- 🌐 **内置 es.exe**: 无需单独安装 Everything 命令行工具
- 🗑️ **回收站机制**: 删除文件移入回收站，支持还原，操作更安全

## 系统要求

- Windows 10/11
- [Everything](https://www.voidtools.com/) 已安装并运行（仅需主程序，无需 CLI）
- Python 3.8+ (仅源码运行需要)

## 安装依赖 (仅源码运行)

```bash
pip install -r requirements.txt
```

## 使用方法

1. 确保 Everything 已安装、运行并建立索引
2. 运行程序：
   ```bash
   python main.py
   ```
   或直接运行打包好的 `DuplicateCleaner.exe`（已内置 es.exe）
3. 点击"浏览..."或"添加目录"选择要扫描的目录 (支持多选、路径粘贴跳转)
4. 点击"开始扫描"等待完成
5. 在结果列表中勾选要删除的重复文件(保留文件默认不可勾选)
6. 点击"删除选中 (创建软链接)"执行清理
7. 文件将移入回收站，原位置创建符号链接指向保留文件

## 设置说明

- **链接类型**:
  - 符号链接: 推荐，NTFS 原生支持，跨目录可用
  - 硬链接: 同一文件系统分区，节省空间
- **最小文件大小**: 忽略小于此大小的文件，单位字节

## 核心原理

### 链接类型对比

| 特性 | 硬链接 | 符号链接 |
|------|--------|----------|
| 跨分区 | ❌ | ✅ |
| 跨文件系统 | ❌ | ✅ |
| 占用空间 | 仅目录项 | 目录项 + 链接数据 |
| 源文件删除 | 数据保留直到所有链接删除 | 链接失效 |
| 权限要求 | 普通用户 | 普通用户 (Win10 1703+) |
| 适用场景 | 同分区重复文件清理 | 通用推荐 |

### 自动回退机制

```
扫描目录 → Everything搜索同大小文件 → xxHash64快速指纹 → SHA256强校验 → 分组展示 → 用户勾选 → 
检测文件系统 → NTFS创建符号链接 / FAT32/exFAT创建硬链接 → 移入回收站 → 验证回收站
```

### 外接硬盘/U盘支持

- **NTFS**: 使用符号链接，原位置完全等同于源文件
- **FAT32/exFAT**: 自动回退到硬链接，同样节省空间
- 无需手动配置，程序自动检测并选择最佳方案

## 打包为可执行文件

```bash
pip install pyinstaller
pyinstaller --clean --noconfirm --onefile --windowed --name DuplicateCleaner main.py
```

生成的 `dist/DuplicateCleaner.exe` (约 51 MB) 可直接分发使用，无需安装 Python，**已内置 es.exe**。

## 快捷键

- `Ctrl+L`: 打开链接分析工具
- `Ctrl+O`: 添加扫描目录
- `F5`: 刷新/重新扫描

## 注意事项

1. **需要 Everything 运行中**，且已建立索引
2. **建议先备份重要数据**，虽然链接操作安全，但删除操作移入回收站
3. **系统盘文件谨慎操作**，可能影响系统稳定性
4. **网络驱动器**建议使用符号链接模式
5. 程序会自动验证文件是否成功移入回收站，失败时自动回退
